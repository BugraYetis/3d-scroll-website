# 🌀 3D Scroll Website

> Three.js ile scroll-driven 3D ürün tanıtım deneyimi

## 🌐 Demo
**[Canlı Demo](https://mae.com.tr/site/3bscrollwebsite/)**

## ✨ Özellikler
- Three.js ile 3D sahne oluşturma
- Scroll pozisyonuna bağlı kamera hareketi
- WebGL shader efektleri
- GLTFLoader ile 3D model yükleme
- Performans optimizasyonu

## 🛠️ Teknolojiler
`Three.js` `WebGL` `GSAP` `ScrollTrigger` `JavaScript`
